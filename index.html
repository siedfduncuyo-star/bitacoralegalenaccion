Panel editorial

Carga de publicaciones

Este panel permite incorporar artículos al sitio sin editar archivos HTML. La carga se realiza mediante un formulario editorial en GitHub y se publica sólo después de la aprobación de una persona autorizada.

Nuevo artículo

Completá título, fecha, categoría, autorías, contactos, resumen, texto completo y bibliografía. También podés pegar o arrastrar imágenes dentro del cuerpo del artículo.

Cargar nuevo artículo → Ver cargas pendientes

Cómo se publica

  1. Una persona del equipo completa el formulario y lo envía.
  2. La carga queda como pendiente en Issues.
  3. Una persona con permiso de escritura revisa el contenido.
  4. Si está correcto, agrega la etiqueta publicar.
  5. GitHub genera la página del artículo, actualiza el buscador, categorías, años y últimas publicaciones.
  6. GitHub Pages refleja el cambio automáticamente.
